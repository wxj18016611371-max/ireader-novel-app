# 掌阅 iReader 手机看小说软件 + 番茄小说在线听书引擎

这是一个专为移动端打造的高沉浸度网络文学阅读应用。书架与阅读体验严格复刻 **掌阅 iReader**，听书功能全面对标 **番茄小说** 的在线 AI 听书体验（**纯在线云端神经网络合成，拒绝机械生硬的离线TTS**）。

---

## 🌟 核心特色与功能

### 1. 掌阅 iReader 经典书架与阅读器
- **九宫格与列表双视图**：
  - 经典九宫格立体书脊、质感渐变封面、已读百分比角标。
  - 列表视图：字数、阅读进度条、最后阅读章节、快速移除管理。
- **本地小说导入**：
  - 支持本地 `.txt` 及 `.epub` 文件拖拽与选择上传。
  - **智能内码识别**：服务端集成 `iconv-lite`，自动识别 `UTF-8`、`GBK`、`GB2312`、`GB18030`，告别乱码困扰。
  - **智能正则章节提取**：自动匹配《第X章》、《Chapter》、《序言》等，自动生成全书章节目录树。
  - 支持文本剪贴板直接粘贴快速入库。
- **掌阅 5 大经典阅读配色体系**：
  - 📜 **羊皮纸**（复古米黄纸质纹理）
  - 🌿 **护眼绿**（舒缓防疲劳）
  - ☀️ **晨光白**（清新极简日间）
  - 📓 **水墨灰**（E-ink 墨水屏质感）
  - 🌙 **深邃夜**（OLED 纯黑省电暗黑模式）
- **精细化排版与翻页**：
  - 字号调节（14px ~ 32px）、行间距、段落缩进。
  - 字体切换（系统黑体、掌阅楷体、文艺宋体）。
  - 支持平移滑动、上下连续滚动以及仿真翻页手感。
  - 章节目录抽屉：正倒序排列、章节搜索、点击直达。
  - 阅读进度与书架数据在浏览器本地持久化保存，断网或刷新不丢失。

### 2. 番茄小说级在线听书系统（纯在线 AI 神经网络合成）
- **拒绝机械生硬离线音**：
  - 采用 Microsoft Edge Cognitive Services 云端神经网络模型，声音逼真自然、情感饱满。
- **8+ 番茄小说精选主播声线矩阵**：
  - **云希（精品男声）**：番茄小说男频玄幻、都市爽文第一招牌主播。
  - **云健（热血评书）**：影视解说、评书演播，极富张力与穿透力。
  - **晓晓（精品女声）**：番茄女频言情招牌，清脆甜美、温润如玉。
  - **晓伊（温柔姐姐）**：情感电台知性御姐，声线柔和治愈。
  - **云扬（沉稳大叔）**：成熟磁性、新闻播音大叔音。
  - **云夏（阳光少年）**：青春阳光，少年感满满。
  - **晓北（东北老铁）**：风趣幽默特色方言。
  - **晓妮（陕西乡音）**：古朴淳厚特色西北风味。
- **番茄式交互组件**：
  - **全局黑胶悬浮胶囊**：书架与阅读器全局浮动可拖拽，黑胶旋转动效与声波跳动，点击展开全屏听书台。
  - **全屏听书操作台**：黑胶大唱片、实时播报字幕卡片、快退 15 秒、快进 15 秒、上一句/下一句、上一章/下一章、连续播放。
  - **声画同步与点句即读**：
    - 听书时，阅读器正文当前句子实时高亮并平滑居中自动滚动。
    - 在阅读器中点击任意一句话，立即从该句在线开播！
  - **在线倍速调节**：0.75x、1.0x、1.25x、1.5x、1.75x、2.0x、3.0x。
  - **睡眠定时关闭**：播完本章自动停止、15分、30分、45分、60分、90分钟，自带倒计时。

### 3. 多端自适应与真机体验
- **电脑端手机仿真外框**：在 PC 浏览器打开时，默认配备 iPhone 15 钛金属外壳与灵动岛视口（390 x 844），可随时一键切换为自适应全屏。
- **手机浏览器直接畅玩**：局域网内用手机访问 `http://<电脑局域网IP>:3000`，即可享受全屏原汁原味的手机触控体验。

## 🚀 快速启动

### 依赖环境
- Node.js >= 18.0.0

### 一键启动
在项目根目录运行：
```bash
# 启动后端服务及全栈生产页面（端口 3000）
npm start
```
在浏览器中打开：
👉 **http://localhost:3000**

### 开发者模式 (前后端热重载)
```bash
# 终端 1：运行后端
npm run server

# 终端 2：运行前端 Vite 开发服务器
npm run client
```
👉 前端热更新地址：**http://localhost:5173**（已内置自动代理后端 API）
